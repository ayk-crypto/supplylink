Goal:
Implement Module 20AI: Customer Detail Screen (Unified Customer View).

Context:
Currently, customer-related data is fragmented across:
- Customers list + edit modal
- Customer ledger screen
- Orders / Quotations lists
- Invoices list
- Attachments panel (in edit modal)

The system now supports strong operational workflows (orders, invoices, routes, attachments, reports), but lacks a single unified customer-centric view.

Core objective:
Create a dedicated Customer Detail screen that becomes the central place to view all information related to a customer, without redesigning the system or changing backend APIs.
